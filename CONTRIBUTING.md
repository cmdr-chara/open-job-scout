# Contributing

Contributions are welcome when they keep OpenJobScout local-first, transparent,
and safe for job seekers.

1. Open an issue for substantial behavior or schema changes.
2. Add or update tests with the implementation.
3. Run `uv run pytest` and `uv run ruff check .`.
4. Do not commit real CVs, application answers, emails, databases, or generated
   reports.
5. Do not add CAPTCHA bypasses, credential harvesting, or automatic application
   submission.

Small, focused pull requests are easier to review and merge.
